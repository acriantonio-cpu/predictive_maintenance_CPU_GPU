# Code of conduct

> English copy of [`CODE_OF_CONDUCT.md`](../../CODE_OF_CONDUCT.md) (Italian); keep them in sync.

The project adopts the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).
In short: respect, inclusive language, criticism aimed at ideas and not at people, no harassment.
Reports go to the maintainers named in [GOVERNANCE.md](GOVERNANCE.md), who handle them
confidentially.
